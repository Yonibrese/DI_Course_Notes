# A/B Testing

## unerstanding A/B Testing

A/B Testing (or split testing) is a randomized controlled experiment used to compare two versions (Control: A, Treatment: B) of a single variable—such as a webpage, email subject line, or machine learning recommendation algorithm—to determine which one performs better against a defined metric (e.g., click-through rate, conversion rate).
